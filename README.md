# ContextAPI

- This project is an e-commerce application built using React, React Router DOM, Axios, Bootstrap, and Context API.

# Preview

![](/public/ContextAPI.gif)

# Properties

- - The project has two pages and category sections, homepage and checkout.

- - There is a filtering feature in the products on the homepage, the products you added to the cart on the checkout page, and the category section.

- - On the Checkout page, you can change the amount of products you add to the cart or remove them from the cart.

- - In the category section, you can filter by all, electronics, jewelery, men's dothing, women's clothing options.

- - Mobile, tablet, and desktop compatibility

- - Modern and sleek design

- - Optimized code structure
